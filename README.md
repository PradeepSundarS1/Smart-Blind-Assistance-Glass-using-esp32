# Smart Blind Assistance Glass using ESP32

## Project Title
- Smart Blind Assistance Glass using ESP32

---

## Abstract
- The Smart Blind Assistance Glass is a wearable embedded system developed to assist visually impaired individuals in safe navigation.
- The system uses ultrasonic sensors to detect nearby obstacles and alerts users using buzzer or vibration feedback.
- ESP32 acts as the central processing unit for sensor monitoring and real-time alert generation.

---

## Introduction
- Visually impaired individuals often face challenges while navigating crowded or unfamiliar environments.
- This project aims to provide a smart wearable assistance system capable of detecting obstacles in real-time and notifying the user instantly.
- The system is lightweight, portable, and suitable for daily usage.

---

## Objectives
- Develop a wearable obstacle detection system
- Improve safety for visually impaired users
- Implement real-time distance monitoring
- Create an efficient alert mechanism
- Design a low-power portable embedded system

---

## Components Used

- Wearable Glass Frame

---

## Software Requirements
- Arduino IDE
- Embedded C / Arduino Programming
- ESP32 Board Package

---

## Working Principle
- Ultrasonic sensor continuously measures obstacle distance.
- ESP32 processes the distance values.
- If an obstacle is detected within a threshold range, alert mechanisms activate.
- Buzzer or vibration motor provides immediate feedback.
- The user navigates safely based on the alerts.
